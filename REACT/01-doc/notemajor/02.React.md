# React Core Concepts - Kiến thức trọng tâm cho Lập trình viên

Nếu OOP có các nguyên tắc SOLID và tính đóng gói, thì React xoay quanh **Functional Programming** (Lập trình chức năng) và **Component-driven Design**.

---

## 1. Tư duy React (React Philosophy)

- **Declarative (Lập trình khai báo):** Thay vì can thiệp trực tiếp vào DOM (Imperative), bạn chỉ cần mô tả UI sẽ trông như thế nào ứng với từng trạng thái (State), React sẽ tự lo phần cập nhật.
- **Component-Based:** Xây dựng UI bằng cách chia nhỏ thành các thành phần độc lập. Mỗi Component quản lý logic và giao diện riêng.
- **Immutability (Tính bất biến):** Bạn không bao giờ chỉnh sửa trực tiếp `state` hay `props`. Khi cần thay đổi, bạn tạo ra một bản sao mới. Điều này giúp React so sánh dữ liệu cực nhanh.
- **Unidirectional Data Flow:** Dữ liệu luôn chảy một chiều từ Cha xuống Con thông qua `props`. Việc này giúp kiểm soát lỗi (debug) dễ dàng hơn nhiều so với luồng dữ liệu hai chiều.

## 2. Các trụ cột kỹ thuật quan trọng

### 2.1. JSX (JavaScript XML)

Cho phép viết cấu trúc HTML ngay trong file JavaScript. Thực chất JSX sẽ được compile thành `React.createElement()`.

### 2.2. Props vs State

| Đặc điểm              | Props                      | State                                  |
| :-------------------- | :------------------------- | :------------------------------------- |
| **Nguồn gốc**         | Nhận từ component cha      | Khởi tạo bên trong component           |
| **Khả năng thay đổi** | Read-only (Bất biến)       | Có thể thay đổi (thông qua hàm set)    |
| **Mục đích**          | Cấu hình cho component con | Quản lý dữ liệu thay đổi của component |

### 2.3. Virtual DOM & Reconciliation

React tạo ra một bản sao nhẹ của DOM thật (Virtual DOM). Khi State thay đổi:

1. React tạo Virtual DOM mới.
2. So sánh (Diffing) với bản cũ.
3. Chỉ cập nhật những phần thực sự thay đổi lên DOM thật (Reconciliation).

## 3. React Hooks (Trọng tâm logic từ bản 16.8+)

Hooks là các hàm cho phép bạn "móc" vào các tính năng của React mà không cần dùng Class Component.

- **`useState`**: Khởi tạo và quản lý trạng thái nội tại.
- **`useEffect`**: Xử lý Side-effects (Call API, lắng nghe sự kiện, dọn dẹp bộ nhớ). Thay thế cho các Lifecycle cũ như `componentDidMount`, `componentDidUpdate`.
- **`useContext`**: Giải quyết vấn đề "Prop Drilling" bằng cách chia sẻ dữ liệu toàn cục trong một cây component.
- **`useMemo` & `useCallback`**: Công cụ tối ưu hiệu năng (Memoization), giúp tránh tính toán lại hoặc render lại các component con không cần thiết.
- **`useRef`**: Truy cập trực tiếp vào DOM node hoặc lưu giá trị bền vững mà không gây render lại giao diện.

## 4. Các kỹ thuật nâng cao cần nắm

1.  **Lifting State Up:** Đưa State lên component cha chung để đồng bộ dữ liệu giữa các component con.
2.  **Higher-Order Components (HOC):** Một function nhận vào một component và trả về một component mới (tái sử dụng logic).
3.  **Composition:** Sử dụng `props.children` để lồng ghép các component, thay vì dùng kế thừa (Inheritance).
4.  **Custom Hooks:** Tự viết Hook riêng để tách biệt logic nghiệp vụ ra khỏi giao diện, giúp code sạch và dễ test.

## 5. Ecosystem (Hệ sinh thái) - Roadmap

Để làm dự án thực tế, bạn cần biết thêm:

- **Routing:** React Router DOM.
- **State Management:** Redux Toolkit, Zustand.

- **Styling:** Tailwind CSS hoặc Styled-components.
